Crowd-cheer stingers for the `/highlight` command's kill sound effects.

Source: Mixkit (https://mixkit.co/free-sound-effects/cheer/), Sound Effects Free License
(commercial use allowed, no attribution required). Original clips trimmed to ~1.3-1.5s
stingers and loudness-normalized (`loudnorm=I=-16:TP=-1.5:LRA=11`).

`cogs/highlight.py` picks one at random per kill event (see `SFX_POOL`).
